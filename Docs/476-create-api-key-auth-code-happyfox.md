# How to create an API Key and Auth Code in HappyFox?

Source: https://support.happyfox.com/kb/article/476-create-api-key-auth-code-happyfox/ (last updated 2020-10-05 08:45:07 UTC)

There are several third-party applications with which you can integrate your HappyFox account with, using an API key and the Auth code of that particular key.

Follow the below steps on how to create an API key and a respective Auth code:

1. Log in to your HappyFox account and head on over to Apps >> Goodies >> API and click "Enable".![](https://hf-files-oregon.s3.amazonaws.com/hdpsupport_kb_attachments/2018/09-11/6b2e6ae4-6393-4e18-89f3-3e42ae20a9fc/Mda2d97adaedb9319825828b8fcbcca5b1536651720020.png)
2. When the page loads, you'll be able to see the list of API keys already configured, along with its status.

![](https://hf-files-oregon.s3.amazonaws.com/hdpsupport_kb_attachments/2020/10-05/79207c79-fd6d-4c2d-9e68-ea9508096eb4/Screenshot_2020-10-05_at_2.07.10_PM.png)

3\. To create a new API key click "+"

1. Give the API key a name (this can be anything as per your preference). If you have any specific throttling requirements for the API, you may modify the respective fields as needed.
2. When done, hit "Add new API key" to create the key.

![](https://hf-files-oregon.s3.amazonaws.com/hdpsupport_kb_attachments/2020/10-05/b927b653-8dba-4747-98cb-7cc61f310961/Screenshot_2020-10-05_at_2.08.34_PM.png)

Once the key is created, you'll be able to see it appear under the list of API keys.

1. To get the Auth code for this key, hover your mouse cursor over this row and click "see auth code".

![](https://hf-files-oregon.s3.amazonaws.com/hdpsupport_kb_attachments/2020/10-05/427cae93-acd1-42db-8dda-6607eb4de46c/Screenshot_2020-10-05_at_2.09.53_PM.png)

You'll then see the both the API key and Auth code appear in the slider.

![](https://hf-files-oregon.s3.amazonaws.com/hdpsupport_kb_attachments/2020/10-05/b5eb9b35-ac1e-47aa-a845-905ff64ac62a/Screenshot_2020-10-05_at_2.11.06_PM.png)

You may then copy and use this API key and Auth code as per your requirements.

To temporarily disable the API keys, simply disable the toggle inside the API key edit slider.

![](https://hf-files-oregon.s3.amazonaws.com/hdpsupport_kb_attachments/2020/10-05/f67e5eee-f595-448c-9272-8b4e315949ab/Screenshot_2020-10-05_at_2.13.27_PM.png)

Please note, if you've recently signed up for HappyFox, your access to the API settings may be disabled. In case you require access to test out the HappyFox API, please send us an email at support@happyfox.com and we'll help you further.
